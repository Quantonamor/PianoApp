# Nutzer-Review: 50 Übende gehen die App durch (2026-10-22)

Methode: 50 typische Nutzer (gruppiert in 10 Profile, je 5 Personen mit unterschiedlichem Fortschritt) gehen den
Ablauf durch: **Installieren → erster Start → Stück wählen/importieren → üben → Fortschritt sehen → wiederkommen**.
Notiert sind die Fragen, die sie stellen würden, was fehlt und was an der Oberfläche besser wäre. Am Ende steht,
was umgesetzt wurde (✅) und was bewusst offen bleibt (⏳).

## Fragen, die echte Nutzer stellen (Auswahl, gruppiert)

**Erster Start**
- „Wo fange ich an? Was soll ich als Erstes spielen?“ (A, C, F) → *Es gab keine Begrüßung/Anleitung.*
- „Was bedeuten die Symbole Sanduhr/Play/Ohr?“ (C, F, I) → *Auf Handys standen nur Symbole ohne Text.*
- „Gibt es mehr Stücke? Vier Demos sind wenig.“ (A, C, G, I) → *Zu wenige eingebaute Stücke.*

**Üben**
- „Mein Digitalpiano hat USB/Bluetooth – kann die App das direkt hören?“ (A, D, E) → *MIDI-Eingang fehlte; das
  Mikrofon ist bei Digitalpianos unnötig ungenau.*
- „Hört die App mein Klavier überhaupt? Wie kann ich das testen?“ (B, F) → *Kein Mikrofon-Test.*
- „Warum geht es nicht weiter?“ (Warte-Modus) (A, C, F) → *Hinweis „Spiele: …“ vorhanden, Akkord-/Loslassen-Hinweise
  jetzt auch.*
- „Kann ich langsamer anfangen?“ (alle Anfänger) → *Tempo-Dialog vorhanden; Tempo-Treppe vorhanden.*
- „Kann ich nur einen schweren Takt üben?“ (B, D, H) → *Zeitleiste/Schleife vorhanden.*
- „Wie halte ich die Hände? Welcher Finger?“ (A, C, F) → *Fingersatz + Hände vorhanden (jetzt realistisch).*
- „Die Leisten verdecken die Noten.“ (I, J) → *Ausblenden beim Spielen + nach 6 s.*

**Fortschritt & Motivation**
- „Wie viel habe ich heute geübt? Habe ich eine Serie?“ (A, C, G) → *Übungszeit pro Stück wurde gespeichert, aber
  nirgends als Tages-/Wochenwert gezeigt.*
- „Welche Stücke kann ich schon?“ (A, C) → *Fortschrittsring auf der Karte vorhanden.*

**Noten importieren**
- „Mein PDF wird nicht richtig erkannt – was tun?“ (H, E) → *Vorschau + Editor + KI-nachbessern vorhanden; Erkennung
  wird laufend verbessert (Konvergenz-Schleife).*
- „Kann ich ein Foto vom Notenheft machen?“ (B, H) → *Vorhanden.*

**Bedienung / Barrierefreiheit**
- „Die Schrift ist zu klein / zu groß.“ (F, J) → *App folgt der System-Schriftgröße (Test mit 130 %).*
- „Hochkant geht nicht.“ (I) → *Dreht jetzt mit dem Sensor.*
